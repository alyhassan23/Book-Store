


# 📚 Book-Store

> A simple book store website built using **HTML**, **CSS**, and **JavaScript** — designed to showcase books with a structured layout, include a contact page, and provide an interactive user experience.

---

## Live Preview
>https://alyhassan23.github.io/Book-Store/

## 🔍 Project Overview

The **Book-Store** project is a lightweight, frontend-focused web application that presents a basic online book store experience. It includes a landing page, styles for product display, interactive behavior with JavaScript, and a separate contact page. This project serves as a practical example of building a static web project using core web technologies and organizing assets clearly for maintainability.

   ```bash

2. Open the project folder
3. Open index.html in a browser to view the homepage
4. Visit contact.html to see the contact page
This is a static site — no backend setup is required.
